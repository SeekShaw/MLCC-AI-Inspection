# EcompVision Inspector

通用的产品尺寸外观检测软件平台：4/6面外观检测机、非标自动化尺寸外观检测机

## 运行方式

直接双击运行：

```
output/EcompVision Inspector.exe
```
程序窗口按 1920×1080 显示器设计，默认大小 1920×1080，最小尺寸 1366×768，启动后默认最大化显示。

## 功能说明

- 用户权限管理：
  - 设备操作员：权限最低，仅能使用一些基本功能，启动/停止/统计/日志等少数几个功能模块。
  - 设备技术员：比设备操作员权限高，可使用更多功能模块，但每个模块仅能使用少数功能。
  - 设备工程师：比设备技术员权限高，可使用更多的功能模块和参数设置。
  - 设备管理员：拥有设备用户管理的权限、添加/删除/编辑用户信息。
  - 系统管理员：拥有最高权限。
  
- 产品方案管理：
  - 新建产品：步骤是引导新建产品，本演示程序是针对电子元件检测行业开发，故将产品类型/规格做了约束，作为通用型软件，可将此约束去掉。
  - 管理产品：可自定义显示产品类型/规格等信息。
  - 支持检测项配置管理：保存至默认、恢复至默认、恢复至出厂等功能
  
- 生产信息统计：
  - 设备编码显示
  - 产品的料号/批号显示，支持拓展连接扫码枪自动录入
  - 定量生产设置
  - 良率统计：支持按剔除口和按缺陷项统计，支持饼图和详情显示，支持按时间/产品检索并导出报表
  - 支持统计配置和统计信息清零

- 运行日志显示：
  - 用户操作信息：支持修改前后查询及恢复
  - 软件运行信息：支持按日期/产品等检索和导出
  - 支持日志导出、清除、冻结查看

- 设备状态显示：
  - 剔除/收料信息：支持满料预警
  - 关键零部件使用次数及寿命预警
  - 关键部件运行状态显示
  
- 成像状态显示：
  - 多相机同时刷新预览：支持开启/隐藏算法结果信息，支持图像源显示切换
  - 调试界面支持相机工作模式切换
  - 支持相机标定及出厂合格性检查
  - 支持检测算法流程方案详细设计，支持定制开发简易性算法插件
  - 调试界面支持源图/R/G/B三通道同时显示
  - 支持检测项规格上下限手动/自动调整
  - 支持检测结果统计及分布图显示，支持CPK计算，支持统计数据检索
  
- 左侧导航栏
  - 调试界面/生产界面切换
  - 功能模块按当前登陆用户权限进行显示
  - 通讯配置：暂未实现
  
- 底部信息栏
  - 关于/帮助信息显示
  - 中英文切换，支持拓展其它显示语言
  - 界面刷新显示图像类别选择：良品图/缺陷图/所有图
  - 缺陷图批量查看：查看当前最新的N张缺陷图，N可以设置
  - 电脑运行状态显示：CPU/CPU/内存等信息显示
  - 软件运行状态显示：开始运行时间、已运行时长等显示
  - 亮色/暗色软件显示背景切换
  
- AI助手
  - 服务配置完成后可进行自然语音对话
  - 支持故障诊断、流程设计与构造、算法调优、检测阈值调整等功能
