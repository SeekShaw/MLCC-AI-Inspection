# EcompVision Inspector

基于两张参考图（生产运行界面 / 调试界面）开发的 Windows 演示 exe 程序。

## 运行方式

直接双击运行：

```
output/EcompVision Inspector.exe
```

演示程序包：`EcompVision Inspector Demo.zip`（仅含最新 exe）。

版本号唯一来源为 `src/app_meta.py`；`python build_b.py` 每次发布**构建前**自动把
第 3 位 +1（到 10 向第 2 位进位），exe 详细信息 / 启动画面 / 关于页三处同步。

程序窗口按 1920×1080 显示器设计，默认大小 1920×1080，最小尺寸 1366×768，支持最大化。

## 功能说明

- 左侧导航栏：
  - 生产运行
  - 8 路相机按钮（与画布相机数量一致），点击任一按钮打开该相机的调试界面
  - 数据报表 / 系统设置 / 用户中心（占位）
- 顶部标题栏：
  - 左上角默认显示「当前产品：MLCC 规格0402 版本Ver01」，可直接编辑
  - 中间放置新建产品、管理产品、启动、停止四个文字按钮
- 左侧导航栏：生产运行、8 路相机按钮、数据报表 / 系统设置 / 用户中心；相机按钮紧凑从上往下排布，底部功能按钮从下往上排布
- 生产运行界面
  - 8 路相机预览（2 列 × 4 行，8 路相机总高度占据整个窗口高度；相机之间保留间隙，每路画布宽度按高度的 1.333 倍布局）
  - 右侧分为两列，均占满整高：左列「设备信息（上）+ 设备运行状态（下）」，右列「生产统计与检测结果（上）+ 运行日志（下）」，列内模块保留可见间隙
  - 所有模块显示框均为可拖拽 / 可缩放面板：按住标题栏移动，拖动边缘/角点调整大小
  - 设备信息：设备编码、负责人独立一行；料号、批号共用一个贯穿两行高度的「扫码录入」按钮
  - 定量生产：带开关按钮，并显示「开启/关闭」文字说明
  - 设备运行状态：每个状态独占一行，状态灯、百分比、数值均置于带边框卡片中
  - 生产统计：总数 / 良品数 / 不良品数 / 重检数 / 良品率 / 不良率 / 复检率 / 平均速度 在同一行显示，双击 KPI 数值可编辑；饼图图例置于右侧 4 行显示
  - 统计操作按钮：统计配置、统计清零、按剔除口统计、按缺陷项统计、按相机统计 在同一行显示
- 调试界面：
  - 主相机画布固定 400×300 像素
  - 右侧 R/G/B 三通道画布各固定 128×96 像素（含间隙总高度 300 像素）
  - 触发模式与冻结/抓取/运行图像按钮放置于主相机画布底部左下角
  - 检测项目表格按剩余有效高度填满，字体统一放大
  - 检测目标信号设置

## 开发环境

- Python 3.13
- PyQt6 6.11
- PyInstaller 6.22

## 源码结构

```
src/
  main.py            # 程序入口
  app.py             # 主窗口与导航
  production_view.py # 生产运行界面
  debug_view.py      # 调试界面
  components.py      # 可复用组件
  styles.py          # 样式与配色
```

## 重新打包

```bash
python build_b.py            # 构建并自动递增版本号（可用 --no-bump 保持当前版本）
python make_demo_zip.py      # 生成 EcompVision Inspector Demo.zip
```

## 更新后发布到 GitHub

程序更新完成后，用仓库根目录的 `push_repo.py` 一条命令完成「暂存 → 提交 → 推送」：

```bash
python push_repo.py                       # 默认提交信息
python push_repo.py "修复某某检测逻辑"     # 自定义提交信息
GITHUB_TOKEN=ghp_xxx python push_repo.py  # 临时用 token 推送（用完即弃，不写入 git config）
```

脚本已内置：
- 绕开本机沙箱对 GitHub TLS 吊销检查的拦截（仅命令级 `http.sslVerify=false`）；
- 默认复用本机已存的 Git 凭据，无需每次粘贴 token；
- **安全护栏**：一旦含明文口令的 `users.json` 被误暂存，立即中止提交，防止泄密。
  （真实 `users.json` 已被 `.gitignore` 排除，仓库仅保留脱敏模板 `users.example.json`。）
