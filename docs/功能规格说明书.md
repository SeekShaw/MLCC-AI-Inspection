## 0. 文档约定

- 「效果」指用户可见的最终确认行为；代码中存在但未连接信号/仅占位的功能，统一在第 9 章列出，不作为功能承诺。
- 「权限」列若无特别说明，指的是 `user_manager.PERMISSIONS` 中的权限键；无权限时控件默认**隐藏**（`permission_ui.apply_permissions` → `setVisible`），检测项列表文本列与剔除位置调试例外（**可见但不可操作**）。
- 「配置键」指落盘的 JSON 字段路径；未标注落盘的参数为会话内存态，重启不保留。
- 用例编号 `TC-XX-NNN`：`MW` 主窗口/导航、`PV` 生产运行、`DV` 相机调试、`DL` 检测项列表、`DS` 设备/触发/剔除设置、`AL` 报警与高级设置、`UM` 用户与权限、`PM` 产品管理、`NW` 其它窗口/弹窗、`CP` 配置与持久化、`RG` 回归基线。

### 1.2 播放与统计口径（理解全局行为的前提）

- 播放节拍 `_play_interval_ms() = 1000 / min_refresh_interval`；默认 `10` fps → **100 ms**。8 路相机同步推进（步长 1、初相位 0），每张样张只占 1 帧。
- 未点「设备启动」前生产信息**不自动刷新**，初始总数为 0；启动后按节拍累计，良率 95~97%、重检率 0~1%，良率+不良率+重检率≈100%。
- 「统计信息」与「运行日志」在生产运行页与 8 个相机调试页之间为**镜像单一数据源**（`StatsPanel.begin_mirror/tick_live/_render_mirror`），调试页不独立维护数据。
- 设备停止后**显示冻结在最后值**；仅高级设置 `设备停止统计清零=True` 时自动清零。

`can()` 判定顺序：用户为空 → False；未知键 → False；超级管理员 → True；`device_code` 非超管 → False；否则查类别矩阵。

默认授权：超级管理员全开；设备管理员（产品/启停/相机调试与标定/图片保存/用户管理/报表/日志/AI/训练/用户中心）；设备工程师＝技术员 ∪ {盒子监控, 运行设置}；设备技术员（含拍照设置/分选/报警/报表/日志/AI/训练）；设备操作员（启停/相机调试/图片保存/报警/报表/日志）。所有类别追加 `user_center` + `glass_clean`；父权限开启自动继承细分项。

权限变更链路：`UserManager.save()` → `normalize_category_permissions()` → 差异比对（矩阵未变**不广播**）→ 监听者 `MainWindow._apply_permissions()` → 递归 `setVisible`/`setTabVisible` → 8 个调试页列权限 → 已开窗口隐藏 → `_sync_reject_debug_state()`。

「可见但不可操作」实现：权限配置表超管整列与 `device_code` 整行 `setEnabled(False)`；设备配置 `QLineEdit.setReadOnly` / `QComboBox.setDisabled`；检测项列表文本列去掉 `ItemIsEditable` 且**列始终可见**；剔除位置调试 5 单选 + 2 复选框置灰可见。
